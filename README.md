# 📚 Bibliothèque App

Une application Android simple, élégante et intuitive pour gérer une collection de livres. 

Ce projet a été développé en **Java** avec **Android Studio** et utilise une base de données locale pour stocker les informations des livres.

## ✨ Fonctionnalités Principales

* **Gestion complète (CRUD) :** Ajouter, modifier, consulter et supprimer des livres facilement.
* **Informations détaillées :** Chaque livre inclut son titre, son auteur, son ISBN, son année de publication et son statut.
* **Statut de disponibilité :** Indicateur visuel clair (Vert = Disponible, Rouge = Indisponible).
* **🔍 Bonus - Recherche en temps réel :** Une barre de recherche personnalisée et optimisée permettant de filtrer instantanément la liste des livres par titre ou par auteur.
* **Interface moderne :** Utilisation de `RecyclerView` pour des performances fluides et design soigné avec une barre de recherche contrastée.

## 🛠️ Technologies Utilisées

* **Langage :** Java
* **IDE :** Android Studio
* **Interface Utilisateur :** XML, RecyclerView, CardView, SearchView
* **Base de données :** Room / SQLite (via `AppDatabase` et `LivreDao`)
* **Gestion de version :** Git & GitHub
